# Agents

- This repository's work is tracked in the Collab project "Collab Project" (issue prefix `CLB`).
- Its seats are Collab Developer (developer), Collab Reviewer (reviewer) and Collab Release (release). Work reaches a seat only as a `CLB` issue assigned to it.
- Work for another project is asked for with `collab seat request`, never handed over in a direct message.
